ZIL - Cloud Rap Vol. 1  (25 presets)  by Trill Tron
=====================================================
Dark, cloudy underground-rap sounds: 808s, bells, plucks, pads, keys, leads, drum kits.
This is a first draft - tell me which presets to change.

REQUIRES the newest ZIL (the version with the USER preset category and SAVE PRESET button).

INSTALL
 1. Close FL Studio.
 2. Copy ALL the .zilpreset files from this folder into:
        Documents\ZIL\Presets\
    (Easiest: open ZIL > SET page > click "OPEN PRESET FOLDER", and paste the files there.
     If the folder doesn't exist yet, open ZIL once and click that button - it creates it.)
 3. Open ZIL, click the USER category in the preset browser (or SET > RELOAD).
 4. Your presets are listed there. Click one to load it.

MAKE YOUR OWN
 Tweak any sound, then SET page > SAVE PRESET. It is saved into the same folder as a .zilpreset
 file that you can share with other people (they put it in the same folder).

Presets are plain XML text files, so they can also be opened and edited in Notepad.
